# Persistent session privacy

Pi Voice Assistant passes the selected session's stable ID to Pi using `--session-id`. Each working directory has its own catalog of named sessions and selection, stored in macOS user defaults. The global shortcut always starts a new conversation. Text and recordings sent from **Open Chat** resume the selected conversation, including after an app restart. Directory paths are standardized and symlinks resolved when choosing the catalog. Existing single-session IDs are migrated to a session named Default. Pi stores session history separately, normally under `~/.pi/agent/sessions/`; Pi configuration and `PI_CODING_AGENT_SESSION_DIR` can change the location. Consult your installed Pi version and configuration before relying on a particular path.

Session files can contain transcripts, responses, tool calls and their outputs, including sensitive file contents. Earlier conversation content may be sent to the configured provider again on later turns. For an unnamed conversation, the bundled title extension sends short excerpts from recent user messages in a separate naming request to the model that answered the turn. Session files and their backups remain accessible to anyone with access to them; do not assume encryption or automatic expiry. Provider, tool and skill services may retain their own copies independently. Review their privacy policies and the README's Privacy and safety section for temporary audio, process arguments and tool access.

Changing working directory selects that directory's catalog; switching sessions or directories does not erase old history. To remove local history, quit the app, locate the relevant Pi session files and remove them and any unwanted backups. Removing the app's stored session ID alone does not delete the files. Deleting local files cannot erase provider or tool copies. Check Pi's documentation and your own backup configuration before deletion. The current implementation does not provide an in-app retention policy or history deletion control.

Cancellation cannot undo tool actions or guarantee that partially written history is removed. Avoid sensitive speech unless these persistence and disclosure risks are acceptable.
